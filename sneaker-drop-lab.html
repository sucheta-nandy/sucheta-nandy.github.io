What does “fair” mean?

FIFO rewards speed. A lottery reduces latency advantage. Risk-aware admission trades false positives for bot resistance.

02

Where must truth be synchronous?

Inventory allocation needs one atomic decision. Notifications and analytics can wait until the order is committed.

03

Which failure deserves a metric?

Server uptime is not enough. Track queue abandonment, oversells, duplicate charges, expired holds, and allocation outcomes.
